Política de Privacidade

Última atualização: 12 de novembro de 2026

Esta política vale para o canal Missão Token e para a Fábrica de Conteúdo, a ferramenta interna que produz e publica as aulas do canal.

1. Quem usa a Fábrica de Conteúdo

A Fábrica roda no computador do responsável pelo canal e é usada só por ele. Ela não é oferecida ao público e não tem cadastro de usuários.

2. Dados do Google que a Fábrica acessa

Com a autorização do responsável pelo canal, dada pela tela de consentimento do Google, a Fábrica usa a YouTube Data API com duas permissões:

  • youtube.upload: enviar ao canal os vídeos e capas que o responsável produziu e aprovou;
  • youtube.readonly: ler o nome do canal e a lista de vídeos enviados, para mostrar o status no painel.

A Fábrica não lê e-mails, contatos, arquivos nem qualquer outro dado da conta Google.

3. Como esses dados são guardados

O token de acesso fornecido pelo Google fica gravado só no computador do responsável pelo canal. Ele não é enviado a nenhum servidor nosso nem a terceiros. Os dados do canal lidos pela API servem só para exibir o painel e não são vendidos, compartilhados ou usados para publicidade.

4. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

5. YouTube e Google

A Fábrica usa os Serviços de API do YouTube. Ao autorizar o acesso, você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

6. Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google. Depois de revogado, o token guardado no computador deixa de funcionar e pode ser apagado pelo painel.

7. Quem assiste às aulas

O público do canal tem de 10 a 14 anos. O Missão Token não coleta dados de quem assiste. Os vídeos são publicados como "feitos para crianças", e o próprio YouTube aplica as regras de proteção de crianças, como a desativação de comentários e de anúncios personalizados.
